# Размещение оболочки в облаке (для нескольких пользователей)

## Что получится
Ссылка, по которой пользователь загружает MIDI, получает оркестровку, слушает MP3 и скачивает ноты.
Оболочка — это `web/app.py` (Streamlit, Python). Вся музыкальная логика — в `src/`, как и раньше.

## Вариант 1. Streamlit Community Cloud (проще всего)
1. Создайте бесплатный аккаунт на share.streamlit.io, войдите через GitHub.
2. Загрузите папку проекта в репозиторий GitHub (можно приватный).
3. В Streamlit Community Cloud: New app → выберите репозиторий → файл `web/app.py`.
4. Нажмите Deploy. Через несколько минут появится ссылка вида `https://<имя>.streamlit.app`.
5. Приватность: в настройках приложения можно ограничить доступ по адресам электронной почты (это платная или ограниченная функция, условия проверьте на сайте сервиса).

Условия бесплатного тарифа (лимиты памяти, «засыпание» приложения без посетителей) могут меняться. Сверьте на сайте перед запуском.

## Вариант 2. Hugging Face Spaces
Создайте Space типа Streamlit, загрузите туда содержимое проекта. Файл зависимостей — `requirements-web.txt`, точка входа — `web/app.py`.

## Что нужно на сервере, которого нет в обычном pip
- `fluidsynth` и `ffmpeg` нужны для MP3. На облачных сервисах их обычно нет по умолчанию. Без них приложение работает, но выдаёт MIDI и ноты без аудио-записи (приложение об этом сообщает).
- Звуковой банк `.sf2` лежит в `soundfonts/`. Для лучшего звука положите более крупный банк.

## Запуск на своём компьютере (для проверки)
```
pip install -r requirements-web.txt
streamlit run web/app.py
```
Откроется адрес http://localhost:8501.

## Перед тем как открыть доступ другим
- Пользователи загружают собственные файлы. Не храните их дольше времени обработки (в приложении так и сделано: временная папка создаётся на один запуск).
- Не загружайте в облако чужие защищённые ноты и не открывайте приложение публично без предупреждения о правах на материал.
- Пометка «прототип, не профессиональная аранжировка» уже выведена в интерфейсе: не убирайте её.
- Лимит размера файла: 2 МБ.
