# Список задач (бери по одной за сеанс; критерий приёмки обязателен)

## A. Качество оркестровки (самое важное)
**A1. Паузы для дыхания.** Сейчас флейта, гобой и кларнет играют 24–28 долей без паузы (QX04) на ноктюрне. Сделать паузы на границах фраз или в каденциях, не теряя более 3% нот мелодии. Приёмка: QX04 равно 0 на `nocturneincsharpminor.mid`, smoke-тест зелёный.
**A2. Ноты, перенесённые на октаву по одной.** На ноктюрне их 95, и контур мелодии местами «прыгает». Подбирать носителей мелодии и сдвиг так, чтобы по одной переносилось не больше 30 нот. Контур не ломать (сдвигать целые фразы). Приёмка: счётчик `octave_shifts` в `out/*_report.json` не больше 30.
**A3. Одна фраза в короткой пьесе.** На 8-тактовом тесте планировщик видит одну фразу, и половина инструментов молчит (QX06). Делить такие пьесы на 2–4 такта и чередовать окраски. Приёмка: QX06 не срабатывает на `test_piano_input.mid`.
**A4. Распознавание арпеджио.** Сейчас фигурация определяется порогом плотности. Нужно по повторяющемуся рисунку. Приёмка: на ноктюрне такты с арпеджио определяются верно (пользователь подтверждает на слух).
**A5. Быстрые пассажи и каденция.** Один подвижный инструмент плюс длинные ноты у остальных (в плане уже есть тип `run`). Приёмка: проверка QX07 и пользователь на слух.
**A6. Ручная правка плана.** Отдельная команда «пересобрать по готовому плану» и проверка формата плана (понятные сообщения об ошибках).

## B. Надёжность и точность
**B1. Диапазоны инструментов.** Заменить `RANGES_UNVERIFIED` проверенным справочником. Источник указать в коде и в `orchestration_rules.json`. Интернет использовать только с разрешения пользователя.
**B2. Проверка нот в MuseScore.** Попросить пользователя открыть `out/*.musicxml` в MuseScore Studio и описать, нет ли ошибок в транспонировании.
**B3. Отдельные партии (по инструментам) и PDF** через `src/render_score_pdf.py`.
**B4. Больше тестовых пьес** из корпуса music21 и от пользователя, регрессионные проверки.

## C. Развитие продукта
**C1. Составы:** трио, квартет, полный оркестр (конфигурации вынести в JSON).
**C2. Аудио на входе** (mp3/wav → MIDI): сначала обзор моделей (например, Basic Pitch), потом квантизация (выравнивание ритма). Только с согласия пользователя.
**C3. Простая оболочка** («перетащи MIDI», кнопка «оркестровать»), локально, без сервера.
**C4. ИИ-планировщик через Claude API:** только по отдельному решению пользователя (нужен ключ и оплата по использованию).
**C5. Экспорт для DAW:** имена дорожек и каналы под библиотеку BBC Symphony Orchestra (проверить по документации библиотеки с разрешения пользователя).
