# Замеры по базе IRCAM (Projective Orchestral Database)

Скрипты замеров от 2026-11-10 (раздел 12.44 в `CLAUDE.md`). Самой базы здесь нет и класть её в репозиторий нельзя
(лицензия в статье не указана): она берётся из репозитория `qsdfo/LOP`, файл `database/LOP_database_06_09_17.zip`.
Пути в скриптах указывают на рабочую папку сессии Claude; перед запуском поправить `ROOT` в `common.py` и пути в начале файлов.

Порядок: `inventory.py` (опись пар и проверка выравнивания) → `analyze.py` (фактура рояля и роли оркестра по тактам)
→ `agg.py` (сводка по видам фактуры) → `pedal.py` (откуда длинные ноты, сколько бегут и держат) → `cont.py` (цельность линий)
→ `cover.py` (какую долю нот рояля играет оркестр). `check_e2.py` сравнивает старый движок и движок 2 теми же мерками.
