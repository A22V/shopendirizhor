# Оркестратор (Шопендирижёр)

Программа берёт пьесу для фортепиано (MIDI или MusicXML) и делает из неё:
- **оркестровку** для камерного оркестра из 10 инструментов (можно с солистом или «как в Болеро»);
- **ансамбль** — дуэт, трио или квартет;
- **переложение** оркестра обратно для фортепиано.

Ещё есть **проигрыватель** (ноты бегут за музыкой), страница **«Анализ и проверки»** и **генератор** — новая фортепианная пьеса по описанию, шаблону или в стиле известной пьесы.

## Где работает
Приложение живёт в облаке Streamlit Community Cloud. Код берётся из этого репозитория: после изменений в GitHub нужно нажать **Manage app → Reboot app**.
Настройки и ключи моделей вписываются в **Streamlit Secrets** (не в код).

## Как ведётся работа
Правки делает Claude. Всё, что нужно знать о проекте (правила, принятые решения, история проб), записано в `CLAUDE.md` — его читают в начале каждой сессии.
Главное правило: программа не слышит музыку. Каждое изменение звука делается парой A/B, а решает слух пользователя.

## Папки
- `web/` — интерфейс (страницы приложения), `src/` — сама программа, `tests/` — проверки (`python tests/smoke_test.py`).
- `docs/` — устройство программы, история, сверка с литературой.
- `soundfonts/` — банки звука для MP3, `input/` — пробные пьесы.
- `tools/` — вспомогательные скрипты для замеров.
