Запись с микрофона: распознавание мелодии в браузере.
basic_pitch.min.js — сборка @spotify/basic-pitch 1.0.1 (Apache-2.0) вместе с @tensorflow/tfjs 3 (Apache-2.0),
esbuild 0.24, формат IIFE, точка входа: window.BP = {tf, BasicPitch, outputToNotesPoly, addPitchBendsToNoteEvents,
noteFramesToTime}. basic_pitch_model/ — модель из того же пакета (model.json + group1-shard1of1.bin).
Статья: Bittner et al., «A Lightweight Instrument-Agnostic Model for Polyphonic Note Transcription and Multipitch
Estimation», ICASSP 2022 (arXiv:2203.09893). Лицензии: LICENSE_basic_pitch.txt.
